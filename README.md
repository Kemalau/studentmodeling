# studentmodeling

Code archive for the unified student-modeling experiments, including scripts, tests, AMLT job specs, manifests, reports, third-party knowledge-tracing checkouts, and the ICLR note draft.

Not included, because they account for almost all of the local disk use:

- `data/` datasets
- `results/` run outputs and downloaded checkpoints
- `models/` weights, including Qwen3-0.6B
- virtualenvs

The experiment tree is `workspace/experiments/unified_student_c1`.
