# C4 novel-number free generation: complete results

## 1. Question and non-goals

The frozen CF1 vision-pad seed-42 checkpoint was tested for donor-rule transfer
under free generation without candidate answers or current-query correct-answer
feedback. The primary contrast is null: directed and real-random state
replacement each match the donor target on 3/81 queries. This experiment does
not support upgrading the earlier candidate-scoring claim to robust executable
rule transfer in open generation. It does not test recurrent state updates or
invalidate a separately measured candidate-scoring effect.

## 2. Sample construction

The frozen seed-42 150-pair manifest supplies donor/recipient identities. First
unique donors, at most three per rule, give 29 selected donors; two fail to
produce three eligible numerical queries before inference (pair indices 83 and
98). The final panel is 27 donors, 11 rules, 81 queries: 54 subtraction,
21 fractions, six decimal-comparison queries. Each donor has three new questions
and one fixed captured trajectory, reused without reading future questions.

The novelty index contains both histories and queries from CF1 training (6,000)
and validation (600), and original MalRule train (9,000), validation (900),
same-template test (900), and cross-template test (900). These are source-file
row counts, not a claim of disjoint or unique examples across files. Canonical
unordered operand/numeric-text combinations must be absent from the union.
A/B/correct targets must differ. A and B targets must be absent from all four
visible histories; each donor's three A targets must differ. Forty-one A targets
also did not occur as fine-tuning target answers. Base-model pretraining novelty
is unknown. Selection uses no model-output scores; source hashes and exclusions
are frozen in the manifest. Generator seed: 20260905, level 9, MEDIUM.

Example: donor rule `fractions.multiply_across_for_division`, query
`2 5/8 ÷ 1 1/2`. Donor target is 63/16, recipient target 7, correct target 7/4.
The decoder receives only the question and the original answer-format
instruction, not these target values. The targets are generated by the original
rule library and used only for evaluation.

## 3. Coordinate, objective, and formula

No new model training, neuron discovery, or layer selection is performed.
Reuse the 64 decoder-block output residuals at the single vision-pad address,
64 × 5120 values. The primary endpoint is

`D_open = (1/81) Σ_q (1[generated_swap(q) = A(q)] − 1[generated_random(q) = A(q)])`.

Here A(q) is the exact rational donor-rule target. Positive means a directed
advantage, not generic output change. Estimate uncertainty with 10,000 paired
bootstrap resamples of the 27 donor groups, retaining the three questions of
each donor together. No likelihood score or gradient is optimized here.

## 4. Arithmetic sign example

For the example above, (21/8) × (3/2) = 63/16 implements the donor's erroneous
division rule, whereas (21/8) ÷ (3/2) = 7/4 is mathematically correct. A query
matching A only under swap contributes +1/81 to D_open; one matching only under
random contributes −1/81. These are metric definitions, not aggregate evidence.

## 5. Real measured example

Group 18, query 2: `950 − 191`, donor rule `subtraction.diff_0_n_equals_n`.
The measured swap output is 761 (A), random output 759 (correct), and native
output 760 (neither A, B, nor correct). This isolated directed hit is retained,
but the same donor fails its other two queries and the native response was not
B. It is not a clean B-to-A flip or a three-query demonstration.

## 6. Selection funnel

Frozen 150 pairs → 29 distinct, rule-capped donors → 27 numerically eligible
donors → 81 fixed queries → five conditions → 405 generated records.
No output-based removal or checkpoint selection. All malformed outputs remain
in denominators. This is a follow-up on existing donor contexts, not wholly new
donor histories; the new numerical query combinations are held out.

## 7. Held-out causal validation

Conditions: native/no patch, own-state no-op, directed donor, real-random donor,
and donor with the recipient's malrule. Random identities are frozen from the
previous real-random audit, family-matched and different from A/B rule IDs.
Only 33/81 queries have an applicable executable random rule; report this
subset separately instead of assuming operation matching.

## 8. Steering definition

At prefill, replace `h_B[layer, state] ← h_source[layer, state]` for all 64
layers (full replacement, no dose search). Original late-fusion attention
masking is retained. Histories are still physically present and masked: this
is not the history-free bridge experiment. Captures contain only instruction
and history through the state address. Each condition and query starts a fresh
KV cache; the fixed donor tensors, not answers or previous-query caches, are
reused across questions.

## 9. Generation and scoring

Qwen3-32B, original CF1 vision-pad seed-42 adapter, NF4 4-bit load with bfloat16
compute, eager attention. Greedy generation, no answer prefill, no candidate
list, no current-query correct answer, maximum 48 tokens, stop at EOS or closing
tag. Original histories retain their feedback. No prompt truncation. Strict
parsing accepts one numeric predicted_response tag or a bare scalar number;
compare exact rational values. No generation hit the token limit. No LLM judge.

## 11. Successes, failures, and formatting sensitivity

The only directed-only strict A match is the 950−191 example above. Its donor
produces 158 instead of A=162 on 320−162 and 10 instead of A=190 on 205−195.
Conversely, on 200−196 random outputs A=196 while directed/native output 4.
Two decimal-comparison A hits also occur natively and under every control;
they do not establish a causal benefit. Decimal comparison can select a number
already present in the question, rather than computing a novel numeric value.

For the division donor, three directed outputs are `1 1/4`, `1 1/2`, `1 1/2`,
versus expected A values 63/16, 27/4, 39/4. These do not become A hits after
mathematically normalizing mixed numbers.

Explicitly post-hoc sensitivity analysis accepts a single mixed number or a
single numeric value with `kg` suffix; it still rejects equations, names, and
multiple guesses. Directed and random both become 6/81 (7.41%), D_open remains
zero with the same CI. One donor now matches all three, but this also occurs
under native, no-op, random, and same-rule conditions: not an intervention gain.
This diagnostic is not a complete semantic parser (e.g. it does not map `Tom`
to a quantity) and does not replace the frozen endpoint.

Post-hoc exclusion of the six decimal comparisons leaves 75 arithmetic queries:
directed and random each 1/75, D_open=0, CI [−0.04, +0.04], no all-three donor.

## 12. Mechanism conclusion and limitations

The tested model does not show a directed advantage in free generation on this
panel. Candidate-scoring evidence alone must not be described as established
open-generation execution of a transferable rule. Conversely, this negative
extension does not prove that the prior state only memorized answers.

The original training prompts supplied candidates and current-query correct
answers. This evaluation removes both and changes numerical combinations at
once. Native B agreement is only 5/81, versus 40/81 mathematically correct
outputs, indicating weak student-error prediction in this format. Distinguishing
format/support dependence, arithmetic demands, and state insufficiency requires
new controlled tests; none is claimed completed here. The two no-op mismatches
also need a separate numerical consistency check before stronger conclusions.
Only seed 42 was tested. This was not a replication of the earlier three-seed
gate, and no new pass/fail gate was retrofitted.
